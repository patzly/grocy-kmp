###_ 1.0.0

Grocy has been rebuilt from the ground up. This is the first release of the new app, the successor of Grocy Android.

#### What is new?

- Every part of Grocy: stock overview with its reports, purchase, consume, transfer and inventory, shopping lists, recipes and meal plan, chores, tasks, batteries, equipment, calendar and all master data
- Pages, forms and lists like in Grocy's web frontend, so you find your way immediately
- A start screen with everything at a glance, in the order you choose
- Layouts for phones, foldables, tablets and desktops
- Shopping lists and their shopping mode also work offline
- Daily notifications about what is due
- Home screen widgets for the shopping list, tasks and calendar
- Several accounts and servers, switched with a swipe on the profile picture
- A Wear OS app with the shopping list and a tile
- A web app with the same features, installable from the browser

#### What changes for you?

- The new app has a different package name. Android treats it as a separate app, so it does not update the previous one.
- Your login is not transferred. Log in once with your server address and API key.
- If you bought the unlock app for Grocy Android, it works here too.
- Once everything works, you can uninstall the previous app.

#### Why a new app?

The new app is written with Kotlin Multiplatform and Compose. The same code powers the Android app, the Wear OS app and the web app, so new features arrive on every platform at once.
